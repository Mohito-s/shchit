# PROJECT_STATE.md — Инструкция для агента Google Antigravity

## 1. Суть продукта «ЩИТ» (@shchit_check_bot / shchit-audit.ru)
Единый сервис проверки подозрительных ссылок, QR-кодов СБП, PDF-договоров/счетов и защиты от угона аккаунтов в мессенджере MAX.
Создатель: Роман (самозанятый / НПД).

## 2. Архитектура без изобретения велосипедов (4 внешних API)
- **2IP.io WHOIS API**: проверка точной даты регистрации домена, ASN хостера и IP.
- **Yandex Safe Browsing API v4**: проверка URL по базе фишинга и социальной инженерии Яндекса.
- **Банк России Warning List API v1.0**: проверка финансовой компании по реестру нелегальных участников и финансовых пирамид ЦБ РФ.
- **DaData ФНС ЕГРЮЛ/ЕГРИП API**: бесплатная проверка ИНН/ОГРН (до 10 000 запросов в сутки).

## 3. Юридическая безопасность (152-ФЗ + табу на ст. 272.1 УК РФ)
- Никакого пробива физлиц. Проверяем только домены, ссылки, метаданные файлов и открытые госреестры юрлиц (ЕГРЮЛ / ЦБ РФ).
- Все загружаемые клиентом файлы (PDF/QR) обрабатываются строго в оперативной памяти (`io.BytesIO` RAM) без записи на диск, ФИО и паспорта маскируются регулярным выражением до анализа.

## 4. Единый Инбокс Комментариев (Автоответчик в 1 клик из бота MAX)
Роман — семейный человек с двумя детьми, у него нет времени мониторить комментарии на 6 сайтах.
Модуль `backend/comment_hub.py` собирает новые комментарии (через Webhook ВК `wall_reply_new`, Osnova API VC.ru, Telegram Bot API и RSS-поллер Пикабу/Хабра), генерирует 3 варианта ответа через правила скилла `anti-ai-humanizer` и присылает их Роману в личку бота MAX с inline-кнопками. По нажатию кнопки ответ публикуется автоматически.
